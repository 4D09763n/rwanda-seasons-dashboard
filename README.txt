RWANDA SEASONS, RAINFALL & DISASTER DASHBOARD

An educational website about Rwanda's seasons, rainfall, and weather-related hazards.

Live website:
https://4d09763n.github.io/rwanda-seasons-dashboard/

Project files:
- index.html: the complete website (HTML, CSS and JavaScript in one file)
- meteo-rwanda.png: Rwanda Meteorology Agency logo
- msar-banner.png: MSAR Maths & Stats Students Rwanda banner
- msar-logo.png: original circular MSAR emblem (backup)

Created by: MSAR - Maths and Stats Students Rwanda
Weather source: Rwanda Meteorology Agency (Meteo Rwanda)

Note: This dashboard is educational. It does not show live weather data or official emergency alerts. For live forecasts and official warnings, visit Meteo Rwanda.
