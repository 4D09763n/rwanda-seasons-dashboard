RWANDA WEATHER DASHBOARD - QUICK START

PROJECT CONTENTS
- index.html: the complete website (HTML, CSS and JavaScript in one file)
- images/meteo-rwanda.png: the METEO RWANDA logo supplied in the conversation
- images/msar-banner.png: the MSAR Maths & Stats Students Rwanda banner supplied for the website
- images/msar-logo.png: the original circular MSAR emblem (kept as a backup)

HOW TO OPEN IN VISUAL STUDIO CODE
1. Extract the downloaded ZIP file to a folder you can find, such as Desktop.
2. Open Visual Studio Code.
3. Choose File > Open Folder.
4. Select the extracted folder named rwanda_weather_dashboard.
5. If VS Code asks whether you trust the folder, choose Trust only if you trust these files.
6. In Explorer, open index.html.
7. Press Ctrl+S if you make changes.
8. If Live Server is installed, right-click index.html in the Explorer panel and choose Open with Live Server.
   If that option is missing, install the extension named Live Server by Ritwick Dey.
9. Your browser should open the dashboard. After edits, press Ctrl+S and the page should refresh.

IMPORTANT NOTES
- Keep the images folder beside index.html. Do not move index.html away from the images folder.
- The dashboard is educational and does not show live weather data or official emergency alerts.
- The rainfall bars are qualitative illustrations, not measured values or percentages.
- For current forecasts and warnings, use https://www.meteorwanda.gov.rw/
- The logos were supplied by the user. Displaying them does not mean either institution has endorsed this project.
- The seasonal month ranges are a broad guide; timing and conditions can vary by location and year.
